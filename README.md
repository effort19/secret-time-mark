# TimeMark Photo Editor

A simple web-based photo editing tool that allows users to add timestamp, location details, GPS coordinates, and verification badges to photos.

## Features

- **Multiple Photo Upload** – Upload and edit multiple photos.
- **Timestamp Editor** – Add date and time to your photos.
- **Location Details** – Display address, barangay, city, and province.
- **GPS Coordinates** – Get location information using device GPS or photo EXIF data.
- **Manual Location Search** – Search and select locations manually.
- **Photo Navigation** – Easily switch between uploaded photos.
- **Customizable Details** – Edit title, area, technology, date, time, and other information.
- **Verification Badge** – Add a verification badge to your photos.
- **Photo Download** – Download edited photos individually or all at once.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- HTML5 Canvas
- Geolocation API
- OpenStreetMap / Nominatim

## How to Use

1. Open the TimeMark Photo Editor in your browser.
2. Upload one or multiple photos.
3. Edit the timestamp, location, GPS coordinates, and other details.
4. Use your device's GPS or manually search for a location.
5. Preview the edited photo.
6. Download your edited photos.

## Requirements

- Modern web browser (Chrome, Edge, Firefox, or Safari).
- Internet connection for location search and reverse geocoding.
- HTTPS connection for device GPS access, except on localhost.
